# 知衡 FinSight：AI 驱动的智能金融分析助手

人工智能通识与数字素养课小组项目。本机运行的中文网页，包含历史行情、企业财务对比、DeepSeek 工具调用问答、双均线回测及可追溯分析简报。参考 Fin-Agent 的自然语言研究思路，独立编写精简实现。

## 启动

1. 双击同目录的 **启动助手.cmd**。
2. 在弹出的本机窗口输入 DeepSeek API Key。输入不显示，也不保存在项目里。直接回车可先体验行情、对比、回测及规则摘要。
3. 浏览器自动打开；保持启动窗口开启。关闭窗口或按 Ctrl+C 停止服务。

Python 需为 3.10 或更新版本。当前电脑可用版本为 `D:\DevTools\Python\Python314\python.exe`，脚本会优先查找可用版本，不会误用已有的 Python 3.5。复制到其他电脑后，如脚本没有找到 Python，可设置 `FIN_PYTHON` 为 Python 程序的完整路径。

无需安装任何第三方生产依赖。浏览器前端、图表与后端全部使用标准能力。Node.js 仅用于开发时运行前端测试，不是运行作品的必要条件。

已有 `DEEPSEEK_API_KEY` 环境变量时跳过密钥提示。可用 `DEEPSEEK_MODEL` 更改模型，默认 `deepseek-flash`，依据开发时官方文档；若账户可用模型发生变化，请修改此环境变量。密钥仅保存在启动进程环境中，请勿写入聊天、截图、报告或代码。

启动脚本自动选择 8765—8785 的空闲端口。若已有预览在运行，新启动页面可能是 8766，请以窗口显示的链接为准。

## 使用

- **市场概览**：默认贵州茅台、2024 年、历史样例。切换公司或日期后点击查询；显示实际覆盖日期、价格、成交量及区间涨跌幅。
- **企业对比**：默认茅台对比五粮液。选择同一报告期，检查披露日期；样例支持 2023、2024、2025 年报。在线模式可查询季度末日期。
- **策略实验**：输入短期/长期均线、资金、手续费和滑点，点击运行回测。查看收益曲线、基准、最大回撤和每笔成交记录。
- **AI 分析**：配置 DeepSeek 后发送问题。模型可调用行情摘要、企业对比、回测工具，回答附数据依据。最多 4 次模型请求、6 次工具调用；单次模型请求超时为 50 秒，不自动重复付费调用。
- **本地摘要**：无需密钥或联网，使用实际数据和固定规则生成摘要，页面明确标为“非 AI”。这不是伪装的模型回答。
- **数据与依据**：查看来源、获取时间和口径；导出简报保存查询参数、数据、分析记录及依据，格式为可编辑 Markdown。

切换公司、日期或模式会清空旧分析，避免把前一组数据的回答混入当前研究。

## 数据与边界

内置真实历史快照：贵州茅台（600519）、五粮液（000858）、招商银行（600036），每家 2023—2025 年日线及三份年报指标。快照文件 `data/samples.json` 保存获取时间及原始查询链接。价格来自腾讯财经前复权历史日线，财务指标来自东方财富。在线适配器为公开接口，可能受网络、限流、上游变更影响；失败会明确显示，不自动用样例替换。

在线名称查询仅映射三家样例公司；其他沪深 A 股请输入六位代码。在线行情限制五年区间，前复权数据不可得时不混用未复权数据。历史数据可能修订，样例并非实时行情。

净利率直接使用数据源公布值。营业总收入、归母净利润、经营现金流分别展示，不用归母净利润冒充总净利润。缺失值显示“—”，不视为零。金融企业与非金融企业不宜直接比较指标高低。年报在次年披露；讨论历史时点应避免引用尚未公开的财报。

回测规则：前一交易日收盘计算均线，下一交易日开盘成交；区间开始空仓，若前日短均线高于长均线则买入，低于则卖出，相等保持。买入持有在区间首日开盘买入。两者均扣设定手续费与滑点，期末按收盘估值，不虚构平仓。默认 5/20 日、10 万元、双边手续费各 3 基点、单边滑点 5 基点。允许连续份额，未模拟整手、涨跌停、停牌成交及税费差异；前复权价格并非当时真实报价。这是教学简化模型，历史结果不代表实际可实现收益或未来表现。

## 项目文件

- `finance.py`：可独立验证的计算与回测。
- `providers.py`：数据校验、公开数据接口及样例读取。
- `assistant.py`：DeepSeek 有界工具调用；密钥只在后台。
- `server.py`：仅监听本机的服务，检查来源并限制静态文件访问。
- `static/`：中文网页与 SVG 图表。
- `tests/`：金融计算、接口、AI 流程及前端工具测试。
- `docs/课堂演示.md`、`docs/问答评估.csv`：展示与验收材料。

## 验证

在项目目录运行：

```text
python -m unittest discover -s tests -v
npm test
```

当前电脑默认 Python 较旧，应改用上述 Python 3.14 完整路径。当前 `npm.ps1` 入口损坏，`D:\AppTools\npm.cmd test` 可正常运行相同的 npm test 脚本。无需安装 npm 包。

更新真实样例可手动执行 `python scripts/capture_samples.py`，它会重新获取并替换本项目样例文件；不是启动必需步骤。

DeepSeek 实际回答质量需要使用你自己的密钥进行最终验证；自动化测试仅对上游传输使用模拟响应，不伪称已经验证真实模型输出。
